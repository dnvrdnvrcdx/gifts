# A Gift For My Beautiful Baby 🌷

A small two-page digital bouquet made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — opening gift page
- `bouquet.html` — animated bouquet page
- `styles.css` — all styling and flower animations
- `script.js` — opening transition

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload all four files to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save. Your gift site will be live after GitHub Pages finishes deploying.

The flower artwork is an original CSS implementation rather than a direct copy of the referenced CodePen.
